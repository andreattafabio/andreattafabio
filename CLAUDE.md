# github.com/andreattafabio (profile README)

Fab's public GitHub profile. GitHub shows `README.md` on the profile page of the account `andreattafabio`.
This repo has only that file. There is no site, no build and no Netlify deploy.

## What is in it

- `README.md`: who Fab is (founder of StudioFab, Friesland), what Fab builds, how Fab works, current work, links.
- Links: studiofab.nl, fabioandreatta.com, LinkedIn (`andreattafabio`), X (`fabioandreatta`).
- Stack line: React, TypeScript, Vite, Tailwind CSS, Supabase, Netlify. Keep it true when the stack changes.

## How a change goes live

- Work on a branch and open a pull request. Fab merges.
- A merge to `main` is visible on the public profile at once. There is no preview.

## Rules

- This repo is public. Never add client names, prices, private data, internal notes or secrets.
- Keep the README short, factual and client ready. English. No emoji, no em dashes.
- Check every link after a change.
