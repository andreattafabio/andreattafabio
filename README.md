## How I work

- **Business outcome first.** A site has to bring in enquiries, bookings or sales, not just look good.
- **Static HTML where possible.** Pages are prerendered, so they load fast on a phone and search engines and AI assistants see the full content.
- **Checks in every build.** Missing titles, dead links and broken structured data fail the build, so a broken version does not go live.
- **Privacy by default.** Self-hosted fonts, no tracking without consent.
- **Documented handover.** Every client repo explains how the site works and where each text lives.
- **Fair terms.** No deposit on website projects: the invoice follows when the site is live.
